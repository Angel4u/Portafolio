# Portafolio Web — Alexander Eastman Galindo (Estetica Persona)

Portafolio profesional desarrollado en **React + Vite**, ambientado en la interfaz del videojuego **Persona** (sin emojis), diseñado para mostrar tus paginas web y conectar directamente por WhatsApp, LinkedIn y Correo.

## Como iniciar el proyecto

1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```
3. Abrir `http://localhost:5173` en tu navegador.

---

## Como agregar o editar tus paginas web

Abre el archivo [`src/data/portfolioData.js`](./src/data/portfolioData.js).

Dentro de la lista `projects` ya viene incluido **AngelitoStudy** como `ARCHIVO #01` junto con plantillas para tus demas desarrollos. Solo debes actualizar el campo `url`, `title` y `description`.
